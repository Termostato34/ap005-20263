# 💻 Scripts Ejecutables de Python (`/Codigos`)

Esta carpeta contiene las implementaciones en código fuente puro de cada práctica en formato `.py`. Para cumplir con las especificaciones técnicas del curso.

## 📄 Archivos Incluidos

### Bloque 1: Python Nativo
* **`neuron1.py`**: Práctica 1 — Modelo $y = wx$ con regla de actualización directa del peso.
* **`neuron1.1.py`**: Práctica 2 — Modelo $y = wx$ utilizando Error Cuadrático y Descenso por Gradiente.
* **`neuron1.2.py`**: Práctica 3 — Modelo completo $y = wx + b$ (peso y sesgo) con descenso por gradiente.

### Bloque 2: Vectorización con NumPy
* **`Primera Práctica Vectorizada (NumPy + Matplotlib).py`**: Práctica 4 — Implementación vectorizada del modelo $y = wx$.
* **`Segunda Práctica Vectorizada (NumPy + Matplotlib).py`**: Práctica 5 — Descenso por gradiente vectorizado y monitoreo de la función de costo.
* **`Tercera Práctica Vectorizada (NumPy + Matplotlib).py`**: Práctica 6 — Modelo afín completo $y = wx + b$ vectorizado.
